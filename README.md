# InstaVibely

InstaVibely is a real-time Instagram content collection and automation platform built with Python, aiograpi MQTT, and PostgreSQL.

It listens to Instagram Direct Messages in real time, automatically captures shared Reels, Posts, and Audio tracks, extracts metadata, and stores everything in a structured database for search, processing, and automation workflows.

## Features

* Real-time Instagram DM monitoring via MQTT
* Automatic Reel, Post, and Audio detection
* Metadata extraction and normalization
* User profile tracking and storage
* PostgreSQL (Neon) integration
* Command-based Instagram bot interface
* Content search and retrieval
* AI-ready content pipeline
* Automation workflow support via n8n
